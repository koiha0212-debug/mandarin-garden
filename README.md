# 慢慢 · 만만한 중국어

HTML/CSS/JavaScript와 JSON만으로 동작하는 중국어 학습 대시보드입니다. 서버·데이터베이스·프레임워크·API 키가 필요 없습니다.

## 주요 기능

- 편집 가능한 대시보드: 일일 목표, 학습자 이름, 주간 학습 시간, 수업 진도
- 수업 6개 / 단어 24개로 시작하는 가상 예시 데이터
- 수업과 단어의 추가·수정·삭제, 검색과 분류 필터
- 수업에 연결된 단어로 생성하는 객관식 뜻 맞히기 퀴즈
- 정답률·학습 시간 저장: 수업 진행률은 최고 퀴즈 정답률
- 한자·병음·뜻·예문 플래시카드와 1·3·7·14·30일 복습 예약
- 중국어 음성 재생(Web Speech API, 중국어 음성이 설치된 브라우저에서 지원)
- 마우스·터치 캔버스 쓰기 연습(필순·발음 자동 채점 없음)
- JSON 내보내기·검증·가져오기·초기 예시 복원
- 서비스 리서치 화면과 원문 링크
- 반응형 CSS Grid, 키보드 접근 가능한 메뉴·모달·입력 폼

## 실행

GitHub Pages 등 정적 호스팅에 `dist/`를 게시합니다. 로컬 실행은 아래와 같습니다.

```sh
python3 -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`에 접속합니다. JSON을 fetch하기 때문에 index.html을 `file://`로 직접 열면 동작하지 않습니다. 빌드·패키지 설치가 필요 없습니다. Google Fonts를 불러올 수 없으면 시스템 폰트를 사용합니다.

## 파일 구성

```text
dist/
  index.html   대시보드·수업·단어장·복습·쓰기·리서치
  style.css    반응형 화면 스타일
  app.js       화면과 학습 동작, 편집 및 JSON 입출력
  model.js     데이터 검증, 날짜·복습·집계 함수
  data.json    초기 가상 데이터
check-model.mjs 데이터와 복습 로직 검증
.github/workflows/pages.yml GitHub Pages 배포
RESEARCH.md 공식 서비스 조사와 적용 범위
```

## JSON 데이터와 저장

`schemaVersion: 1`이며 `settings`, `vocabulary`, `lessons`, `activity`, `results`로 구성됩니다.

- settings: 이름과 일일 학습 목표
- vocabulary: 한자·병음·한국어 뜻·분류·예문·해석·기억 단계·복습일
- lessons: 수업명·설명·레벨·주제·학습 시간·진도·연결 단어 ID
- activity: `YYYY-MM-DD` → 분 단위 학습 기록
- results: 퀴즈 날짜·수업 ID·정답 수·문항 수

UI에서 수정하면 localStorage에 JSON 문자열로 저장합니다. localStorage는 브라우저의 로컬 키/값 저장 기능이며 별도의 데이터베이스나 서버를 사용하지 않습니다. 서버의 `data.json` 자체는 수정하지 않습니다. JSON 내보내기로 파일에 저장하고 가져오기로 다른 브라우저·기기에 옮기세요. 데이터 삭제·다른 주소·다른 브라우저에서는 자동 동기화되지 않습니다. 백업은 사용자가 관리해야 합니다.

가져올 때 5MB 크기 제한, 필수 필드·문자열 길이·정수 범위·실제 날짜·ID 중복·수업 단어 참조를 검사합니다. 미리보기 후 사용자가 교체해야 적용합니다. 사용자 입력은 HTML 이스케이프하여 표시합니다. 가져오기는 전체 교체 방식입니다.

가상 기록의 기준일은 2026-10-28입니다. 나중에 열면 초기 주간 학습 시간은 0일 수 있습니다. `기록 수정`에서 현재 주 기록을 입력하세요. 연구 화면의 레벨은 자체 학습용 분류이며 공식 HSK 등급 판정이 아닙니다.

## GitHub Pages 배포

1. GitHub에 빈 저장소 `mandarin-garden`을 만듭니다(무료 Pages 사용 시 공개 저장소).
2. 이 프로젝트 내용을 저장소 루트에 올립니다. `dist/` 폴더만 올리지 말고 `.github/workflows/pages.yml`도 포함하세요.
3. Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택합니다.
4. `main`에 push하면 워크플로가 검증 후 `dist/`를 배포합니다. 필요하면 Actions에서 수동 실행합니다.
5. Actions의 배포 환경에 표시되는 실제 URL로 접속합니다. 저장소 이름이 바뀌어도 상대 경로를 사용하므로 동작합니다.

계정·조직 정책, Actions 및 Pages 권한에 따라 관리자의 추가 설정이 필요할 수 있습니다. 이 설정은 저장소 생성이나 Pages 활성화 권한을 자동으로 부여하지 않습니다.

## 확인

```sh
node check-model.mjs
```

JSON 왕복, 빈 데이터, 잘못된 날짜·중복 ID·참조 오류·음수 시간, 연말 복습 일정과 주간 집계를 확인합니다. 별도 패키지는 사용하지 않습니다.


## 2026-10-29 발음·상하이 여행 자료

기본 데이터는 11개 수업, 39개 단어·표현(기존 24개 + 여행 표현 15개)입니다. 공항·교통·음식점·쇼핑·미술관 각 3개 문장을 제공합니다. 상하이어가 아닌 표준중국어를 사용합니다.

`schemaVersion: 1`을 유지하며 단어에 선택 문자열 `koreanPronunciation`(200자), `toneNotes`(500자), `wordBreakdown`(1000자)를 추가했습니다. 누락한 이전 JSON도 가져올 수 있습니다. 일치하는 기본 단어 ID·한자·병음의 빈 필드만 보완합니다. 임의 단어의 발음을 자동 생성하지 않습니다. 수정·내보내기·다시 가져오기에서 새 필드가 유지됩니다.

기존 브라우저 저장본에 새 수업을 자동 추가하지 않습니다. **데이터 메뉴 → 상하이 여행 자료 15개 추가**를 선택하면 기존 단어·진도·기록을 보존하며 없는 ID만 추가합니다. 삭제했던 자료도 이 버튼을 누르면 다시 추가됩니다. 같은 ID가 있으면 기존 자료를 우선합니다.

한국어 표기는 보조 근사치이며 병음·표준중국어 음성을 우선합니다. 음성은 원어민 녹음이 아닌 기기의 zh-CN/cmn 합성 음성입니다. 해당 음성이 없으면 설치 안내를 표시하며 다른 언어·방언으로 대체하지 않습니다. 0은 경성, 숫자는 음절 순서, 화살표는 성조 변조를 나타냅니다.

검증: `node --check dist/app.js`와 `node check-model.mjs`. 이전 JSON 호환, 선택 필드 검증·왕복, 추가 자료 중복 방지 및 사용자 기록 보존을 검사합니다.


### 날짜별 오늘의 단어
- 기기의 현지 날짜 기준으로 추천합니다. 자정 이후 열린 화면은 30초 이내 또는 탭 복귀 시 갱신합니다.
- 최근 추천 3개(단어가 적으면 단어 수−1개)를 제외한 뒤 복습 예정일 도래 여부 → 낮은 기억 단계 → 이른 예정일 → 날짜별 순서로 선택합니다.
- 같은 날에는 복습·단어 추가·새로고침 후에도 같은 ID를 유지합니다. 해당 단어 삭제 시 다시 선택합니다. 단어가 1개면 다음 날에도 같은 단어가 표시됩니다.
- 추천 이력은 별도 localStorage 키 `mandarin-garden-daily-word-v1`에 최근 60일을 저장합니다. 기존 `mandarin-garden-v1`과 schemaVersion 1 JSON은 그대로 유지합니다. 추천 이력은 JSON 백업에 포함되지 않으며 기기·브라우저별로 다를 수 있습니다.
- 저장이 차단되면 열린 화면의 메모리에서 유지합니다. 브라우저 저장 삭제 시 추천 이력도 초기화됩니다.
- 검증: `node check-model.mjs` 및 `node check-daily-word.mjs`. GitHub Pages 배포 전 두 검사를 실행합니다.

## 듣기·자가 녹음·비교 연습 (2026-11-03 제안)

각 단어·여행 문장·예문에서 **듣기·녹음 비교**를 열고 표준음 듣기 → 내 발음 녹음 → 녹음 종료 → 비교 재생 순서로 연습합니다. 표준음과 내 녹음을 3회 번갈아 재생하며 각각 직접 반복 재생하거나 중지할 수 있습니다. 한글 근사치·병음·성조 설명은 단어 연습 창에도 표시합니다. 예문에는 단어의 병음·성조 설명을 잘못 붙이지 않습니다.

- 표준음은 원어민 녹음이나 상하이어가 아닌 로컬 zh-CN/cmn 합성 음성입니다. 기존 듣기 버튼도 로컬 음성만 사용합니다. 로컬 음성이 없으면 듣기가 비활성화되며 설치 안내를 표시합니다. 음성 목록이 늦게 로드되면 갱신합니다.
- 마이크는 녹음 버튼을 눌렀을 때만 요청합니다. HTTPS 또는 localhost가 필요합니다. 권한 거부·마이크 없음·다른 앱 점유·API 미지원 안내를 제공합니다.
- MediaRecorder에서 WebM/Opus, MP4, Ogg/Opus 지원을 탐색하고 없으면 브라우저 기본 형식을 사용합니다. 시작 실패도 처리합니다.
- 최대 30초·8MB, 메모리 내 녹음 하나만 유지합니다. 다시 녹음·삭제·창 닫기·페이지 이동 시 정리하며 녹음 종료 즉시 마이크 트랙을 해제합니다. 권한 요청 중 닫거나 취소한 뒤 늦게 허용되어도 트랙을 해제합니다.
- 탭 숨김·휴대전화 화면 전환 시 녹음·재생을 중지합니다. 비교 자동 재생이 차단되면 직접 재생 버튼을 사용합니다.
- 녹음 업로드·다운로드·영구 저장·자동 채점이 없습니다. JSON 백업에 녹음이 포함되지 않습니다. 기존 뜻 맞히기 정답률과 발음 정확도는 별개입니다.
- schemaVersion 1, 학습 저장 키, 날짜별 추천 키, 기본 데이터, 복습 계산은 변경하지 않습니다. 기존 주소에서 배포하면 기존 기록이 유지됩니다.

검증: `node check-model.mjs`, `node check-daily-word.mjs`, `node check-speaking.mjs`, `node --check dist/app.js`, `node --check dist/speaking.js`.
음성 검사는 API 모의 환경에서 상태·권한·자원 해제를 검증하며 실제 마이크 음질이나 모바일 OS 동작을 보증하지 않습니다.

실기기 점검 (아직 미실시): iOS Safari / Android Chrome의 HTTPS 페이지에서 최초 허용·거부 후 설정 변경·다시 녹음·비교 3회·중지·삭제·화면 잠금·탭 전환·뒤로가기·로컬 중국어 음성 유무를 확인하세요. 인앱 브라우저에서 권한 요청이 막히면 Safari/Chrome에서 직접 엽니다. 320px 폭에서 버튼과 대화상자 스크롤을 확인하세요.

배포 영향: 새 정적 모듈 speaking.js 추가, app.js와 CSS 및 자산 버전 갱신, 배포 전 음성 로직 검사 추가. 서버·API 키·패키지 설치·DB 마이그레이션은 필요 없습니다. main 반영 시 기존 Actions가 Pages를 자동 배포합니다. 별도 브랜치만 반영하면 현재 워크플로에서는 배포되지 않습니다.
